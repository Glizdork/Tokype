# Contributing to Tokype

Thanks for your interest in Tokype!

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes.
4. Test them.
5. Open a pull request.

## What we welcome

- Bug fixes
- New tests
- Documentation improvements
- Performance improvements
- New optimizer patterns for TitanJerboa

## Before you open a PR

- Make sure the project builds: `go build ./...`
- Run the test scripts and confirm nothing broke.
- Keep changes focused — one feature or fix per PR.
- Follow the existing code style.

## Reporting bugs

When reporting a bug, include:

- The `.tp` script that reproduces it
- The output you got
- The output you expected
- Your OS and Go version

## Code of conduct

Be respectful. We're here to build a language together.

Good luck!
